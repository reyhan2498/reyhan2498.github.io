Vendor onboarding & invoice exception portal

Legacy Blue Prism UI scrapers were handling vendor registrations and messy PDF invoices. They broke constantly and cost a lot to keep alive. I replaced them with an API-first cloud portal.

Problem

High operating costs and frequent break-fixes. Every UI change upstream snapped a bot.

Solution

An automated portal: vendors self-serve, AI reads the PDFs, APIs validate, humans only see real exceptions.

Impact

~90% less manual handling, exceptions resolved in minutes not days, zero scraper maintenance.
